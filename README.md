## ✨ ไฮไลต์

- **ทะเลสมจริงแบบเรียลไทม์:** คำนวณผิวน้ำด้วย FFT บนการ์ดจอ ผสมคลื่นหลายขนาดให้ไม่ซ้ำลาย
  - คลื่นยกตัวและม้วนแตกเป็นฟองเมื่อเข้าใกล้ฝั่ง น้ำซัดขึ้นหาดแล้วไหลกลับ
- **สีน้ำเปลี่ยนตามความลึก:** น้ำตื้นใสสีเทอร์ควอยซ์ ทะเลลึกสีน้ำเงินเข้ม มีแสงลายน้ำบนพื้นทรายใต้น้ำ
  - แสงทะลุสันคลื่น ผิวน้ำสะท้อนท้องฟ้าและเมฆ
- **ท้องฟ้าตามหลักฟิสิกส์:** สีฟ้า รุ่งอรุณ และอาทิตย์อัสดงคำนวณจากการกระเจิงของแสงในชั้นบรรยากาศ
  - เมฆเป็นสามมิติ ลอยตามลม และหนาขึ้นเมื่อพายุเข้า
- **กลางวันและกลางคืน:** ดวงอาทิตย์กับดวงจันทร์เคลื่อนตามตำแหน่งจริงของเกาะในทะเลอันดามัน กลางคืนมีดาวและทางช้างเผือก
- **เกาะที่มีชีวิต:** อ่าวทรายหันไปทางทิศตะวันตกให้เห็นพระอาทิตย์ตก แหลมหินสองฝั่ง ป่าดิบชื้นบนเขา และต้นมะพร้าวที่ไหวตามลม
- **ระบบอากาศครบ:** ฝน หิมะ และพายุที่มีฟ้าผ่า เสียงฟ้าร้องดังช้ากว่าแสงตามระยะทาง
  - ทรายเปียกเมื่อฝนตก หิมะสะสมบนพื้นและยอดไม้ หยดฝนเกาะเลนส์กล้อง
- **ดำน้ำได้:** ลงไปมองผิวน้ำจากด้านล่างได้ พร้อมหมอกและเสียงแบบใต้น้ำ
- **เสียงรอบทิศทาง:** คลื่น ลม ฝน ฟ้าร้อง และนกนางนวล สร้างด้วยโค้ดทั้งหมด
- **ไม่ต้องโหลดไฟล์ภาพหรือเสียง:** ภูมิประเทศ ต้นไม้ texture และเสียงสร้างขึ้นขณะเปิดเกม

## 🛠️ เทคโนโลยี

`Next.js` · `React` · `TypeScript` · `three.js (WebGL2)` · `React Three Fiber` · `GLSL` · `Web Audio API` · `Tailwind CSS`

<details>
<summary>รายละเอียดเทคนิคกราฟิก</summary>

- **Ocean:** Tessendorf FFT บน GPU (Stockham radix-2 ผ่าน multiple render targets), JONSWAP spectrum พร้อม directional spreading
  - แบ่งเป็น 3 cascades, ฟองจาก Jacobian ที่ค้างอยู่ข้ามเฟรม และ cross-fade เมื่อเปลี่ยน spectrum
- **Shoreline:** คลื่นเดินตาม signed distance field ของชายฝั่ง, shoaling ตาม Green's law และแตกที่ H ≈ 0.78·depth
  - มี swash sheet ที่ขอบน้ำเรียบระดับ pixel
- **Water shading:** Fresnel reflection ของ sky + clouds, GGX sun glitter, screen-space refraction
  - Beer–Lambert absorption, crest subsurface scattering, caustics, Snell's window และ rain ripples
- **Sky:** single-scattering แบบ Rayleigh + Mie + ozone, volumetric clouds บน Perlin–Worley 3D noise, ดาว, ดวงจันทร์ และทางช้างเผือก
- **World:** เกาะ procedural แบบ deterministic, GPU instancing ของต้นมะพร้าว ป่า หญ้า และหิน
  - ลมพัดต้นไม้ใน vertex shader และเงาไหวตามใบไม้
- **Post-processing:** auto exposure, bloom, ACES tone mapping, หยดฝนบนเลนส์, เอฟเฟกต์ใต้น้ำ, vignette, film grain และ SMAA

</details>
